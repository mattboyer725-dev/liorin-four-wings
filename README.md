# LIORIN Chess Academy — four wings

Teach on the board. Hold in the cold engine. Hunt BOT titles only. Keep every game.

**Live:** [liorin-chess-prod-vercel.vercel.app](https://liorin-chess-prod-vercel.vercel.app)

**Source:** [mattboyer725-dev/liorin-four-wings](https://github.com/mattboyer725-dev/liorin-four-wings)

This is a **new** public product. It is not the school `liorin` repo and not the earlier academy deploy.

## Wings (kept separate)

- **Academy** — original teaching board
- **Conquest** — agent command floor and Lichess field for [@Liorin22](https://lichess.org/@/Liorin22)
- **Combined** — both on one nav
- **8-bit** — NES cart, pixel board, own engine skin

## Charter

Engines versus bots only. No human-pool assistance. Personal API tokens stay on the device — never in git, never in the campaign database.

## Stack

TanStack Start, React 19, Tailwind v4, chess.js, Neon/PGLite.

Fair-play. Always pointing home.
